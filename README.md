# Master Minds Design Studio

Build a separate, standalone interactive UI design playground named “Master Minds Design Studio” for reviewing a complete education platform UI. IMPORTANT: This is a separate design-only project. Do NOT connect to, import, edit, deploy over, or modify the existing Master Minds app, GitHub repository, Supabase database, or Lovable project. Do not require authentication or backend. Build a polished responsive web app with a left navigation sidebar listing pages grouped by categories and a main preview area showing real, implemented interactive UI mockups. Add desktop/tablet/mobile viewport toggle, page search, category filters, and next/previous page controls. Use React, TypeScript, Tailwind and shadcn/ui. Style direction: premium academic + gamified learning, deep navy sidebar, white/soft-gray canvas, vivid royal-blue primary actions, restrained gradients, rounded cards, clear typography, subtle shadows, strong spacing. Master Minds brand and tagline “Learn. Compete. Level Up.” Create individually selectable pages, each rendered as its own designed interface (not a collage and not generated images). Implement at least these page mockups: Welcome/Landing, Login, Sign Up, Academic Setup, Student Dashboard, Academic Dashboard, Quiz Selection, Quiz Taking, Digital Library, AI Tutor, Study Planner, Revision Mode, Flashcards, Exam Mode, Multiplayer Lobby, Tournaments, Leaderboard, Community Feed, Friends, Chat, Notifications, Student Profile, Avatar Creator, Rewards Store, Settings, Parent Dashboard, Teacher Portal, Admin Portal, Manager Dashboard, Finance Portal, Super Admin / Owner Control Center, Academic Insights, Learning DNA, Topic Coverage, Early Learner Home, Early Games, Early Quiz, Early Videos, Early Discover, Early Progress, Early Collection, Early Profile, Early Leaderboard, Content Admin, Migration / System Tools, Loading, Empty State, Error, and Access Denied. Every listed page must be selectable in the sidebar and render a distinct, credible layout using reusable components and realistic sample data; make the primary buttons and navigation work in the prototype where sensible. Do not claim to connect real data or real authentication. This is a design review playground only. Prioritize completing a usable, visually polished first version with all page routes represented. Do not use image generation; build actual HTML/CSS UI.
